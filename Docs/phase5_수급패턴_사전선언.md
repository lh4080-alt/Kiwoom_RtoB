### 정규화 (사전 고정)
- 일간 비율 `ratio_X,t = net_X,t / tv_t`
- 20일 누적 비율 `cum20_X,t = Σ_{t-19..t} net_X / Σ_{t-19..t} tv`
- 롤링 z (point-in-time) `z_t = (v_t − mean(v_{t-60..t-1})) / std(v_{t-60..t-1}, ddof=1)` — 당일 미포함

### 합 제약 처리
외인 + 기타외국인 + 기관 + 개인 + 기타법인 + 국가 ≈ 0 이다.
- **부호 패턴(2-1)**: 외인·기관·개인 세 부호를 쓴다. 범주형이라 중복이 해롭지 않고, 기타법인·기타외국인·국가가 반대편을 맡는 조합(+++, −−−)도 그대로 둔다.
- **회귀·군집(2-3, 2-4)**: 외인·기관 두 축만 쓴다. 개인 ≈ −(외인+기관+기타)라 정보가 중복되므로 넣지 않는다.
- **흡수율(2-2)**: 기관과 외인만 쓴다.

## 3. 분석 정의

### 2-1 부호 조합 패턴 (일별 / 20일 누적 각각)
부호: 값 > 0 → "+", 그 외 "−". 강도: 해당 주체 z60 |z| ≥ 1 → 강, 미만 → 약 (기술 통계·전방 로그 전용, 검정 셀 아님).

| 패턴 (외인/기관/개인) | 이름 |
|---|---|
| + + − | 외인·기관 동반 매수형 |
| + − − | 외인 단독 매수형 |
| + − + | 외인·개인 매수형 |
| − + + | 기관 방어형 |
| − − + | 개인 단독 흡수형 |
| − + − | 기관 단독 흡수형 |
| + + + | 3자 동반 매수형 |
| − − − | 3자 동반 매도형 |

### 2-2 흡수율
- 일간 `A_t = 기관_t / |외인_t|` (외인_t < 0인 날만 정의)
- 20일 `A20_t = cum20 기관 / |cum20 외인|` (cum20 외인 < 0인 날만)
- 검정 셀: A·A20 각각과 타깃의 Spearman IC (원형 이동). 5분위 표는 기술 통계(분위 경계는 그 시점까지 확장 창).

### 2-6 외인 매도 종료 확인
- 트리거: 외인 cum20 비율의 z60 ≤ −2
- 확인: 트리거 후 20거래일 안에 외인 일간 순매수 > 0이 **N = 3일 연속** → 그 3번째 날이 신호일
- 연속 발생: 신호 후 새 트리거는 신호일 + 20거래일 이후에만 인정 (첫 발생만)
- 대상: 시장, 반도체 블록. 타깃: 신호일 종가 기준 5·20·60일 선행수익률

### 2-5 실적 이벤트 스터디 (참고 — 검정 셀 아님)
- 이벤트: 네이버 공시 중 제목에 "영업(잠정)실적"이 있고 "(정정)"이 아닌 공시. 삼전은 일 ≤ 15 → 잠정, > 15 → 확정으로 분리
- 반응일 D = 공시 시각이 그날 15:30 전이고 KR 거래일이면 그날, 아니면 다음 KR 거래일
- 선반영 = D 전 20거래일 수익률 (close_{D−1}/close_{D−21}), 반응 = D 당일 수익률
- 발표 후 = 진입 E = D 다음 거래일 시가, 1·5·20일 후 종가 / 시가(E) − 1
- 동반 수급: D 직전 20일 패턴(2-1 누적)과 D 이후 20일 패턴을 기록. 에피소드별 표 그대로 첨부

### 2-4 외부 변수 연결
- 종속: 외인 일간 비율 (시장, 블록 각각)
- 설명변수: ① 원/달러 당일 변화% (ECOS 731Y003/0000003, 15:30 종가) ② 원/엔 당일 변화% (ECOS 731Y001/0000002) ③ 전야 SOX 수익률 (t 이전 마지막 미국 세션) ④ 전야 미10Y 변화(bp) ⑤ 전일 KOSPI 수익률
- 모형: OLS, 창 t−250..t−1로 적합 후 t 예측 → 설명분 ŷ_t, 잔차 e_t. 둘 다 z60(당일 미포함)
- 검정 셀: 잔차 z ≤ −1 / 설명분 z ≤ −1 각각 조건부
- 라벨 비교: 현재 ③ 괴리有 vs 잔차 기반 괴리有(px5 > 0 AND 블록 외인 잔차 20일 합 < 0), 타깃 KOSPI

### 2-3 20일 누적 군집
- 축: 외인·기관 cum20 비율의 z60 (2축)
- k = 4 고정, KMeans(n_init=20, random_state=0), 표준화는 적합 구간 기준
- walk-forward: 매월 말 그 시점까지의 데이터로 재적합 → 다음 달 매일 배정. 최초 적합은 2016-07 (2년 축적 후)
- 라벨 정렬: 중심의 외인 좌표 오름차순 C1..C4 (C1 = 외인 매도 극단)
- 채택 조건: 같은 날짜 구간에서 군집 라벨의 r20 설명력 η²가 2-1(누적 패턴)보다 크고, 군집 셀 중 하나 이상 합격. 아니면 미채택

## 4. 검정·합격 기준 (모든 분석 공통)
- 타깃: 방향 = 선행 5·20일 수익률(평균·중앙값·하락확률), 변동성 = |선행 5·20일 수익률|. 2-6은 5·20·60일
- 통계량: 조건부 평균 − 전체 평균 (IC 셀은 Spearman IC)
- null: 조건 마스크(또는 x)를 타깃에 대해 원형 이동, 2,000회, 이동량 60 ≤ k ≤ N−60, 양측 p
- CI: 조건부 평균의 블록 부트스트랩 95% (블록 길이 = horizon), 2,000회
- 다중검정: Phase 5 전체 셀을 한 가족으로 BH-FDR q ≤ 0.10. 누적 셀 수는 config/data/verify/cell_registry.json에 기록하고 Bonferroni 임계를 병기
- 안정성: 2014-07~2019-12 / 2020-01~ 두 구간 효과 부호 일치
- 에피소드 의존: 연속일 = 1 에피소드. 타깃 합의 절대값 기여 상위 2개 에피소드 제외 후 부호 유지
- 표본: n < 30 또는 에피소드 < 10이면 "참고" (합격 불가)
- **합격 = FDR 통과 AND 부호 일치 AND 상위 2 제외 유지 AND 표본 충족**
- 결과 표기: 미합격은 "해당 기준에서 미검출". 폐기는 사용자 결정

## 5. 표시 규칙
- 합격 전: 사실 정보만 — 오늘 패턴 이름, 기관 흡수율, 외인 20일 누적 금액. 패턴별 수익률·확률 미표시

- 전방 로그 항목: 3자 패턴 이름·강도, 흡수율, 군집 라벨, 외인 설명분·잔차, 매도 종료 신호 플래그

## v1.2 표시·흡수율 v2 (2026-10-10, v1 본 실행 결과 산출 후 — Lee 결정)

v1의 정의·임계값·합격 기준은 바꾸지 않는다. 아래는 표시 규칙과 별도 버전 추가만이다.

### 표시 (브리프)
- 방향 합격 2셀만, **해당 상태일 때만** 1줄: "참고: <상태> — 과거 같은 상태 n회·에피소드 k건·이후 h일 기저 대비 ±X%p (전방 검증 중)".
  값은 v1 본 실행(cells.csv, 시드 20261010)으로 고정하고 매일 재계산하지 않는다. 기저 = 같은 대상의 전체 평균.
  - 하닉 20일 누적 ++− (외인·기관 순매수 + 개인 순매도) — h = 5 (합격 타깃이 r5. 20일은 미합격이라 쓰지 않음), n 653·에피소드 76·+1.41%p
  - 시장 군집 C1 — h = 20, n 422·에피소드 50·+2.29%p
- C1 정의 (쉬운 말): **외인 대량 매도 + 기관 대량 매수 (20일 누적, 평소 대비)**.
  근거 — C1 배정일(434일) 외인 20일 누적 z 평균 −1.64(89%일 순매도), 기관 +1.58(88%일 순매수).
  외인 최근 5일이 20일 평균보다 나은 비율 51%(다른 군집 43~52%) → '매도 둔화' 상태는 아니다.
- 변동성 합격 3셀(−++ |5일| 시장·블록·하닉)은 표시하지 않는다 — 변동성 줄(ATR)과 겹치고, RV 통제 시 효과 36~71% 축소(supp_cells.csv). 상태는 전방 로그에 남는다(flows3_*_pat_cum20).
