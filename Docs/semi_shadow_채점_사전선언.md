# semi 섀도 신호 채점 — 사전 선언 v1 (2026-10-10, 채점 전 고정)

섀도 신호(semi_shadow.jsonl의 `new_signal`, `new_signal_v2_sox_only`)를 나중에 채점할 때의 원천·조인·수익률 정의를
**채점 전에** 고정한다. 채점 시점에 원천을 고르면 그 자체가 선택 편향이다. 바꾸면 v2로 새로 기록한다.

## 1. 사후 수익률 원천
- 종가: **k81 확정 패널** `config/data/breadth_k81_panel.parquet` (ka10081 수정주가, 무접미사 = KRX 단독).
  최종일 행은 05:35 브리프가 확정치로 추가하고, 주간 refresh(일 03:00)가 ka10081로 재작성한다.
  2026-10-10 대조: 최근 30거래일 22종목 660건 불일치 0.
- 시가: ka10081 수정주가 `open` — **20:30 이후 또는 다음 날 수집분만**.
- 사용 금지 원천: MDC 일봉(15:35 수집 — 마지막 봉 미확정, 10/8 사례), semi DB `price_change`(16:00 수집, 10/6~10/8 무효),
  macro jsonl `semis_*`(20시 전 수집분 무효).

## 2. 신호 행 (조인 규칙)
- 포함: `invalid`가 없고 `logged_at`이 05:20~05:45(RtoB_Semi_Snapshot0530 정규 실행)인 행만.
- `date`는 P(그 아침 기준 직전 KR 거래일). 형식 혼재(YYYYMMDD·ISO) → `YYYY-MM-DD`로 정규화 후 조인.
- 다른 로그(4축 forward_log 등)와의 조인은 이 규칙으로 채점 시에만 한다. 기록 시점 조인은 폐지(2026-10-10 — 테스트 행만 잡히던 문제).
- 섀도 행이 없는 날은 결측 (채우지 않음).

## 3. 수익률 정의
- 진입: P 다음 KR 거래일 E의 시가 (섀도 기록 05:30 → 같은 날 개장).
- 청산: E부터 세어 h번째 거래일 종가. h = 5, 20 (시장상태 모니터 지시서 7절).
- 대상: 005930, 000660 각각.
- 비교: 신호=1 행 평균 − 같은 기간 정규 행 전체 평균 (기저 대비). 수수료·슬리피지 미반영 (별도 표기).
- 판정 기준: Phase 5 사전선언 §4와 동일 (원형 이동 null, 블록 부트스트랩 CI, 두 구간 부호, 상위 2 에피소드 제외, n·에피소드 하한).

## 4. 기록된 사실 (변경하지 않음)
- 섀도 지표(ATR 백분위·ADX·이격도 등)는 **P 전 거래일 봉** 기준이다 (05:30 실행에서 `iloc[-2]` — 마지막 행을 '당일'로 가정한 코드).
  확정 데이터 역산으로 12행 전부 확인. 결과적으로 MDC 미확정 마지막 봉은 쓰지 않았다. 지표를 P 봉으로 바꾸려면 v2.
- 무효 처리한 행: 정규 실행이 아닌 4행(10/6 13:57, 10/7 11:00 수동 테스트, 10/10 14:33 date 6/1) — `invalid._row`.
  이 테스트 행에서 읽힌 4축 전방 로그 10/7 `signal_mu_sox`와 macro jsonl 10/7 `axes_signal`도 무효.
